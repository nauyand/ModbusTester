# ModbusTester

Aplikasi Android untuk menguji perangkat Modbus (Kotlin + Jetpack Compose).

## Spesifikasi
- Package: `com.teknosolvo.modbustester`
- minSdk 24, targetSdk/compileSdk 35
- AGP 8.7.3, Kotlin 2.0.21, Gradle 8.11.1

## Menjalankan
1. Buka folder ini di Android Studio (Ladybug atau lebih baru).
2. Tunggu Gradle sync selesai.
3. Run ▶ ke emulator atau perangkat.

Atau lewat CLI:

```bash
./gradlew assembleDebug
```
